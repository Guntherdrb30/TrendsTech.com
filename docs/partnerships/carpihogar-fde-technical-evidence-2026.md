## Evidence hierarchy
- **Code/repository evidence:** verified by reviewing the connected GitHub repositories.
- **Repository documentation:** feature claims in README; needs runtime confirmation for production assertions.

## CarpiHogar — anchor implementation
The CARPIHOGAR.COM repository's README describes a unified e-commerce, ERP and AI system for furniture/home commerce. Its package.json includes Next.js 15, React 19, Prisma, MCP SDK, OpenAI Agents SDK, FFmpeg, Three.js, React Three Fiber, NextAuth, bcrypt, Nodemailer, and more.

**Documented business domains:** public storefront, catalog, checkout, POS, stock, purchasing, finance, logistics, suppliers, partner and investor portals, design projects and AI marketing.

**Documented external integrations:** OpenAI API / Responses API / Agents SDK, Meta Graph API, Meta Ads, WhatsApp Cloud API, Google OAuth, email via SMTP, Vercel and Neon.

**Documented identity and governance:** credential and OAuth login, JWT sessions, role-based dashboards, validation, auditing and security controls. Do not describe this as independently certified.

**Code-level signals:** scripts for Marketing Studio foundation and persistence tests, load tests for storefront/product/order operations, email diagnostics, image optimization and health checks. Existence of scripts does not imply all checks pass.
