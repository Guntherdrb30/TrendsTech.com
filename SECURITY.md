# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to **trends172tech@gmail.com** with the subject **Security**.

Include the affected service, reproduction steps, potential impact, and any supporting evidence. Do not include credentials or personal data in the report unless requested through a protected channel.

We ask researchers to:

- Avoid accessing, changing, or deleting another person's data.
- Avoid service disruption, social engineering, spam, and denial-of-service testing.
- Allow a reasonable investigation and remediation period before public disclosure.

Trends172Tech LLC will acknowledge a valid report, investigate it, and share status updates when reasonably possible. This policy does not create a bug-bounty program or authorize activity that would otherwise be unlawful.

## Supported versions

Security updates are applied to the current production version of `trends172tech.com`. Older deployments and local development snapshots are not supported.
